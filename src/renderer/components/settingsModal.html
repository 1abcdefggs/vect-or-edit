closeClosing

Confirm before closing
Ask first when you close something with ×, so a stray click cannot close it. Tabs with unsaved changes are always asked about.

terminal System log

Log panel at startup
Whether the log panel is open when the app starts.
Log time format
How the time of each log line is shown. The stored time is always the same; only the display changes.
Log time zone
Show the time in this computer's time zone, or in UTC. ISO 8601 is always UTC.
Remember layout
Remembers the height of the log panel and the chat dock and the width of the sidebar, and restores them at the next start. Turning it off forgets them.

visibilityParts of the window

Show or hide each part of the window with its eye button. Essential parts cannot be hidden.

buildApplication Maintenance

Reload Editor Window
Redraws the editor window only; the app keeps running. Nothing is deleted.
Restart Application
Closes the whole app and starts it again, including the engine and background processes.
Clear Application Cache
Clears Electron session cache and temporary renderer resources. It does not delete documents, Knowledge Slots, settings, downloaded model files, or API keys.
Restore Default Settings
Resets preferences (theme, language, layout, AI provider, search options) to their defaults, then reloads the editor.
Dev reset
Same as the reset above, but keeps the model files, the API keys, the loaded KNOWLEDGE and guideline, and the save folder. The first-run setup shows again.
