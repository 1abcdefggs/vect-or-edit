cloud_sync Cloud Vector Embedding (API Vectorizer)

CLOUD API
Cloud vector embedding allows you to use external API services for semantic search and vectorization. This is useful for high-accuracy embeddings or when you want to offload processing to a cloud service. Please configure your API key in the LLM tab to enable this feature.
Cloud Vectorizer Status
High-precision offline search (384-dimensional HNSW / ONNX) is currently enabled by default. If you wish to use embeddings via a cloud API, please configure your API key in the LLM tab and enable the corresponding adapter.

Application Maintenance

Clear Application Cache
Clears Electron session cache and temporary renderer resources. It does not delete documents, Knowledge Slots, settings, downloaded model files, or API keys.
Restore Default Settings
Deletes renderer preferences such as theme, language, editor layout, AI provider selection, and search options, then reloads the editor. It does not delete documents, Knowledge Slots, cached model files, or the encrypted Gemini API key.
Reload Editor
Reloads the editor window and renderer process. It does not clear settings, cache, documents, models, or API keys.
Restart Application
Closes and relaunches the Electron application. It keeps settings, documents, cached models, Knowledge Slots, and encrypted API keys.
